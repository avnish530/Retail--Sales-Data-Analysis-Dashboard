# Retail Sales Data Analysis & Dashboard

## Project Overview

This project focuses on analysing retail sales data using Excel, SQL, and Power BI.

## Tools & Technologies

- Excel
- SQL
- Power BI
- Data Analysis
- Data Visualization

## Project Work

- Cleaned and analysed retail sales data using Excel and SQL.
- Performed region-wise and customer-level sales analysis.
- Identified sales trends and patterns.
- Created an interactive Power BI dashboard.
- Analysed key sales KPIs.
- Generated business insights to support decision-making.

## Key Analysis

- Total Sales
- Total Profit
- Sales by Region
- Sales by Customer
- Sales Trends
- Product Performance
- Profitability Analysis
